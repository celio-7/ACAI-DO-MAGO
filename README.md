## 🎯 Tema
Desenvolvimento de uma **landing page conceitual** inspirada na marca real **Açaí Mago**, com o objetivo de representar digitalmente seus valores visuais e sensoriais por meio de uma experiência envolvente e mágica.  
Projeto desenvolvido como requisito acadêmico da disciplina de Desenvolvimento Front-End.

---

## 🧠 Objetivo
Criar um site **interativo, acessível e responsivo** que apresente o conceito visual e os produtos da Açaí Mago. O projeto visa aplicar competências práticas de:

- UI/UX Design  
- HTML5 semântico  
- CSS3 responsivo  
- JavaScript para interações  
- Organização de projeto front-end  
- Documentação e publicação  

---

## 🎯 Público-Alvo
Jovens e adultos de **14 a 35 anos**, apreciadores de sobremesas naturais, saudáveis e conectados ao digital e à estética de marca.

---

## 💼 Justificativa do Negócio
A Açaí Mago é uma marca real reconhecida por sua estética vibrante e sabor marcante.  
O projeto acadêmico utiliza sua identidade visual como inspiração para treinar habilidades de:

- Identidade visual  
- Prototipagem  
- Desenvolvimento web  
- Experiência do usuário  
- Design responsivo  

O site NÃO possui fins comerciais — trata-se apenas de um exercício acadêmico.

## 🗂️ Resumo das Partes do Projeto

### **📌 Parte 1 – Estrutura e Planejamento**
- Definição do negócio e objetivo  
- Criação do wireframe/mobile e desktop  
- Estrutura de pastas organizada  
- HTML base criado com semântica  
- Separação de componentes (header/footer)  
- Documentação inicial no README  

### **📌 Parte 2 – Estilos e Interações**
- Aplicação de CSS moderno  
- Ajustes de responsividade  
- Interações com JavaScript  
- Aperfeiçoamento da experiência do usuário  
- Revisão visual e acessibilidade inicial  

### **📌 Parte 3 – Publicação, Otimização e Testes**
- Otimização de imagens  
- Minificação de CSS e JS  
- Testes multi-navegador e dispositivos  
- Checklist e documentação final  
- Publicação via GitHub Pages  
- Reflexão individual e em dupla
