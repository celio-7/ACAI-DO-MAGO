# Avaliação – Projeto “Açaí do Mago”
Dupla avaliada: **Arthur Vinicius e Célio Dantas**
Dupla avaliadora: **Antonio Melo e Daphine Coelho**

---

## 1. Navegação e Exploração

**Nível sugerido:** Em Desenvolvimento (2/4)

A navegação é simples e permite acesso às seções principais através dos botões presentes na página.  
No entanto, não há um menu fixo ou navegação clara entre páginas, o que limita a exploração do conteúdo.

**Pontos observados:**
- Botões funcionam corretamente
- Estrutura linear de navegação

**Limitações:**
- Ausência de menu superior
- Falta de páginas separadas
- Usuário depende de rolagem manual

Sugestão: implementar um menu de navegação e links internos com âncoras.

---

## 2. Responsividade

**Nível sugerido:** Iniciante / Em Desenvolvimento (1,5/4)

O site apresenta problemas de adaptação em telas menores.

**Pontos positivos:**
- Alguns elementos reduzem de tamanho

**Limitações / oportunidades:**
- Textos e imagens ultrapassam a tela
- Botões ficam desproporcionais
- Layout desalinha no mobile

Sugestão: aplicar media queries e ajustar containers e imagens.

---

## 3. Design e Identidade Visual

**Nível sugerido:** Proficiente (3/4)

O design é coerente com o tema de açaí, utilizando cores roxas e imagens relacionadas.  
O layout apresenta uma proposta visual temática e atrativa.

**Pontos fortes:**
- Paleta de cores relacionada ao produto
- Imagens que reforçam a identidade
- Tema bem representado

Sugestão leve: padronizar espaçamentos e tipografia para profissionalizar o visual.

---

## 4. Código, Estrutura e Modularização

**Nível sugerido:** Iniciante (1/4)

O repositório apresenta apenas um arquivo HTML principal, sem estrutura organizada.

**Pontos observados:**
- Código todo concentrado em um único arquivo
- CSS interno ou pouco separado
- Ausência de pastas organizadas (css, img, js)

**Oportunidades de melhoria:**
- Separar CSS e JS em arquivos externos
- Criar pastas organizadas
- Modularizar partes repetitivas (ex.: cards)

Essas melhorias facilitariam manutenção e expansão do projeto.

---

## 5. Acessibilidade

**Nível sugerido:** Iniciante (1/4)

O site apresenta pouca preocupação com acessibilidade.

**Pontos observados:**
- Falta de `alt` adequado em imagens
- Botões sem descrição acessível
- Contraste pode ser melhorado

Sugestão: adicionar `alt`, labels, e foco visível em elementos interativos.

---

## 6. Conteúdo e Alinhamento ao Negócio

**Nível sugerido:** Proficiente (3/4)

O conteúdo apresenta bem a proposta do site, mostrando produtos e elementos relacionados ao tema.

**Pontos positivos:**
- Tema bem definido
- Apresentação clara do produto
- Identidade comercial reconhecível

Sugestão: adicionar informações como preços, endereço, contato ou cardápio, tornando o site mais funcional.

---

## 7. Interatividade

**Nível sugerido:** Iniciante (1/4)

A interatividade é mínima.

**Pontos observados:**
- Botões levam a seções

Oportunidades:
- Implementar formulário funcional
- Adicionar efeitos hover
- Criar microinterações

## 8. Documentação, README e Repositório

**Nível sugerido:** Iniciante (1/4)

O README contém apenas o básico e não apresenta informações relevantes sobre o projeto.

**Pontos observados:**
- Título
- Link do projeto

Sugestão incluir:
- Descrição do projeto

Com melhorias na responsividade, organização do código e documentação, o site pode evoluir bastante e se aproximar de um projeto mais completo e profissional.
